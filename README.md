# Final State Exam

Study material for MUNI BCS state exam - law and security studies

Study material for MUNI BCS state exam - IT

## Struktura

- `main.tex` only assembles the document and contains the shared preamble.
- `1.tex` to `12.tex` and `15.tex` to `23.tex` contain the individual exam questions. Questions 13 and 14 are not present in the original repositories.
- `uvod-IT.tex`, `uvod-BSS.tex` and `stavova-tabulka.tex` contain the original introductory sections.
- `zaverecne-poznamky.tex` contains the closing review sections and sources.
- `assets/` contains the images used by the questions.
